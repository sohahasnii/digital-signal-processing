# 📡 DSP-MATLAB basic projects
(lab experiments/conceptual understanding)

A collection of **Digital Signal Processing (DSP)** projects and experiments designed to build practical understanding of signals, systems, and digital signal processing techniques in MATLAB.

The repository starts with fundamental DSP concepts and gradually moves toward practical applications such as **digital filtering and audio processing**.

## 📚 Topics Covered

* Signal Generation
* Sampling & Reconstruction
* Convolution
* Correlation
* Fourier Transform
* Fast Fourier Transform (FFT)
* Digital Filters
* Audio Signal Processing
* Noise Reduction

## 📂 Projects

| # | Project                  | Description                                                         |
| - | ------------------------ | ------------------------------------------------------------------- |
| 1 | Signal Generation        | Generate and visualize basic discrete-time signals.                 |
| 2 | Sampling                 | Explore sampling and reconstruction of signals.                     |
| 3 | Convolution              | Implement and understand discrete-time convolution.                 |
| 4 | Correlation              | Explore correlation between signals.                                |
| 5 | FFT                      | Analyze the frequency components of signals using FFT.              |
| 6 | Digital Filters          | Implement basic low-pass and high-pass filters.                     |
| 7 | Audio Processing         | Apply DSP techniques to real-world audio signals.                   |
| 8 | Audio Noise Reduction    | Reduce unwanted noise from an audio signal using digital filtering. |
