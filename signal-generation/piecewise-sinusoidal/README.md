##Piecewise Sinusoidal Signal Generation Using MATLAB
#Overview
This project generates and plots a sinusoidal signal with three different frequencies over three consecutive time intervals using MATLAB.

In this program , a piecewise sinusoidal signal is generated by changing the frequency of the sine wave at specific time intervals. Three input frequencies (f1, f2, and f3) are used to generate the signal over a total duration of 3 milliseconds.

The signal is divided into three intervals:

0–1 ms: Sine wave with frequency f1.
1–2 ms: Sine wave with frequency f2.
2–3 ms: Sine wave with frequency f3.
MATLAB uses a sampling frequency to create discrete time samples. A for loop and conditional statements select the appropriate frequency for each time sample. Finally, the plot() function displays the signal against time in milliseconds.

Why This Program?
This program demonstrates how a signal can be generated with different frequency characteristics over time. It helps develop a basic understanding of sinusoidal signals, sampling, time-domain visualization, and conditional signal generation in MATLAB.

Piecewise signal: A signal defined by different expressions over different time intervals.
Conditional statements: Used to choose which frequency applies at each instant.

Key Observations
A higher frequency produces more oscillations within the same time interval.
A lower frequency produces fewer oscillations within the same time interval.
The amplitude of the sine wave remains between −1 and +1.
Frequency changes may cause abrupt changes in the waveform at interval boundaries.
The sampling frequency should be sufficiently high to represent the input frequencies accurately.

Expected Output

A time-domain plot showing a sinusoidal signal across three consecutive intervals, with each interval using a different user-defined frequency.
The waveform can be used to observe how changing the frequency affects the number of oscillations within each interval.

Result

    frequency 2: 3000
    frequency 3: 1000
