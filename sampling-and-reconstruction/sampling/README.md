# Sine Signal Sampling in MATLAB

## 📌 Project Description

This project demonstrates the generation of a basic **sine wave** and its representation using a sampling frequency in MATLAB.

The program generates:

* An original sine signal with frequency `f0 = 2000 Hz`
* A sampling frequency of `Fs = 50 × f0`
* Five cycles of the sine wave
* A sampled representation using a stem plot

## Concept

This MATLAB program demonstrates the generation of a sinusoidal signal and its sampling.

A sine wave is defined by:

x(t) = sin(2πf₀t)

where:
- f₀ is the frequency of the input sine signal.
- Fs is the sampling frequency.
- t is the time vector.

The input frequency is set to **2 kHz** and the sampling frequency is chosen as **50 times the input frequency** to obtain a smooth representation of the signal.
